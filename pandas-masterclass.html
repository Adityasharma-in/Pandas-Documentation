1.1 Core Concepts

What is Pandas? Pandas is the foundational data manipulation library for Python — it translates low-level NumPy array math into tabular, spreadsheet-like structures. Think of it as Excel on steroids with a Python brain: every cell is backed by fast C-level NumPy arrays, but you interact through clean high-level commands.

Engine Rules & Mechanics

ConceptRule
OriginBuilt by Wes McKinney in 2008 at AQR Capital to solve the lack of fast data analysis tools in Python
EngineBuilt on NumPy — every Series/DataFrame stores data in contiguous ndarray blocks
ExecutionEager execution — operations run immediately and produce in-memory results
CoW DefaultPandas 3.0 enables Copy-on-Write by default. No operation modifies the original unless you explicitly assign
Memory StrategyEach column is a separate NumPy array — mixed types are supported at the column level, not row level

1.7 Copy-on-Write (CoW) Paradigm

CoW changes everything. In Pandas 3.0, Copy-on-Write is enabled by default. No operation modifies the original DataFrame unless you explicitly assign the result. This eliminates SettingWithCopyWarning and makes behavior predictable.

Engine Rules

  • Selection creates a lazy copy: df2 = df[df["a"] > 0] does not copy data until you modify df2
  • No chained assignment: df[df["x"] > 0]["y"] = 5 silently does nothing — use .loc
  • Explicit copy needed for independence: Use df.copy() when you need a truly independent copy
  • Performance win: CoW avoids unnecessary copies, saving memory and CPU time
  • Opt-out: pd.set_option("mode.copy_on_write", False) to restore legacy behavior

Live Lecture Code

import pandas as pd df = pd.DataFrame({"x": [1, 2, 3], "y": [10, 20, 30]}) # CoW: subset does NOT share data — it will copy on first write subset = df[["x"]] # This modifies only 'subset', NOT the original 'df' subset["x"] = [100, 200, 300] print("Original df:") print(df) print("Subset (CoW isolated):") print(subset)

4.1 Feature Generation

Create new columns. New columns don't require loops — assign the result of an expression to a new column name. The expression runs on every row simultaneously (vectorized).

Engine Rules

  • df["new"] = df["a"] + df["b"] — element-wise arithmetic
